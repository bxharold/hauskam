how do I start and stop services on bootup using systemctl?

To manage whether a service starts and stops automatically on bootup, use  (to start at boot) or  (to prevent it). Note that these commands do not affect the current running state, only how the service behaves during system startup. [1, 2]  
Quick Commands (Requires ) 

To automatically start a service on bootup: 
   sudo systemctl enable [service_name]
To enable the service AND start it immediately, use 
  sudo systemctl enable --now [service_name]

To prevent a service from starting on bootup: 
  sudo systemctl disable [service_name]
To disable the service AND stop it immediately, use  
  sudo systemctl disable --now [service_name])


| Task  | Command | Description  |
| --- | --- | --- |
| Start immediately | sudo systemctl start [service_name]   | Starts the service now. (Does not persist after reboot)  |
| Stop immediately  | sudo systemctl stop [service_name]    | Stops the service now. (Does not persist after reboot)  |
| Start on boot     | sudo systemctl enable [service_name]  | Configures the service to automatically launch at next boot.  |
| Disable on boot   | sudo systemctl disable [service_name] | Removes the service from startup triggers (will not launch on boot).  |

Helpful Verification Commands 

• Check if a service is set to start on boot:  systemctl is-enabled [service_name]
• Check if a service is currently running:     systemctl is-active [service_name]
• View all enabled/disabled services:          systemctl list-unit-files --type=service
